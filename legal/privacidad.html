Política de Privacidad

Esta política describe, de forma general, el tratamiento de datos que realiza ZELETAS a través de su sitio y servicios digitales. Debe revisarse con los datos jurídicos reales del titular antes de operar comercialmente.

Datos tratados

Podemos tratar nombre, correo electrónico, teléfono, datos de cuenta, datos de anuncios, mensajes, pedidos y datos necesarios para prestar los servicios solicitados.

Finalidades

Gestionar cuentas, anuncios, mensajería, soporte, pedidos, pagos, prevención del fraude, moderación y comunicaciones solicitadas.

Proveedores y encargados

La plataforma utiliza proveedores tecnológicos, entre ellos Supabase para autenticación y base de datos, Google para el acceso OAuth, Twilio para SMS de autenticación, Stripe para pagos y Stripe Connect para pagos a vendedores, y Netlify para alojamiento. Estos proveedores tratan datos conforme a sus propias condiciones y, cuando corresponda, como encargados del tratamiento.

Conservación

Los datos se conservarán durante el tiempo necesario para cada finalidad y durante los plazos legales aplicables.

Derechos

Puede solicitar acceso, rectificación, supresión, limitación, oposición y portabilidad escribiendo a infozeletas@gmail.com, sin perjuicio de otros derechos reconocidos legalmente.

Seguridad

Se aplican autenticación, control de acceso, RLS, separación de secretos y medidas técnicas orientadas a reducir accesos no autorizados.

Contacto de privacidad

infozeletas@gmail.com. La existencia de un Delegado de Protección de Datos dependerá de las obligaciones reales del titular.
